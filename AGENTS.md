# Repository guidance

Read [How to exercise engineering judgment](agent-stack/JUDGMENT.md) and apply it when working here. On production ML changes, use the [working agreement](production-ml-working-agreement.md) for the affected release criteria. When working with specialists, use the [delegation guide](agent-stack/ROUTING.md) and the roles the current host has registered.

Keep the original trial inputs, saved responses and their hashes intact. Edit role definitions in the [role manifest](agent-stack/roles.json), regenerate the host files, and run the repository validator when changing the pack.
