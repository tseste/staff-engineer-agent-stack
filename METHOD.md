# Staff engineer skill screening

50 real third-party SKILL.md packages, pinned to Git commits on 2026-10-18. Each receives a fresh subagent with no inherited conversation, its exact source skill, and one prewritten scenario. Linked local references are available. Agents produce concrete work products and do not grade themselves. The parent evaluates each result.

Rubric: 0-2 each for decision quality, use of evidence/uncertainty, tradeoffs/risk, concrete action, and proportionality. Keep requires at least 8/10, no critical safety/correctness omission for the scenario, and useful distinct coverage in a staff-engineer toolkit. Drop can mean failed trial, poor general fit, or unnecessary overlap; it is not a universal verdict on the skill.

Expected behaviors were written in manifest.json before agents ran. Trial agents see only their own scenario, not the criteria. These are single-case qualitative scenario tests, not controlled proof that a skill improves the underlying model, executable production validation, or a security audit. The same underlying model and a single parent evaluator limit independence and generalizability. Sources are downloaded for evaluation only; no skills are installed or activated globally.
